## Agent skills

### Issue tracker

暂无外部 issue tracker，issue/spec 以本地 markdown 文件形式存放在 `.scratch/` 下。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认的五个分诊标签：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

single-context：`CONTEXT.md` + `docs/adr/` 均位于仓库根目录。See `docs/agents/domain.md`.
